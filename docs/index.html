Archaeopteryx.js

A browser tool for the visualization and analysis of highly annotated phylogenetic trees.

GitHub · npm

Open your own tree →

Paste or open a Newick, NHX, Nexus, phyloXML or Auspice / Nextstrain JSON file and see it visualized right here. The tree is read locally in your browser — nothing is uploaded.

Live demos

Free software (GNU LGPL). Runs entirely in your browser on d3 — no plugins, no server.
