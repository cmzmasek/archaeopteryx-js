Control panel
=============

Every control of the Archaeopteryx.js control panel, section by section in
the panel's order, with the icon it draws and what it does. The words are
the control's own tooltip, as the panel's cheat sheet lists them (the card
button in the panel header, "Control panel: what each control does"); no
row shows a live value. The panel draws a control only when the tree on view
gives it something to do, so this is the union over the 26 demo trees of
``demo.html``, and the last column says which of them show the control.
A control with two icons shows the one for what the next click will do. The
Download section ends with the formats of the Download… button's menu, each with
the sentence the menu shows for it.

     - rectangular layout: the root at the left, the tips in even rows down the page
     - all demos
   * - |circular|
     - circular layout: the tree as a fan, every tip label carried out to a common ring
     - all demos
   * - |unrooted|
     - unrooted layout: equal-angle, drawing no root branch at all
     - all demos
   * - |phylogram|
     - phylogram: branch lengths drawn to scale, so the tips end ragged. Greyed in the circular layout, which always carries its labels to the outer ring, so there the aligned phylogram is the one drawn
     - all demos
   * - |aligned_phylogram|
     - aligned phylogram: branch lengths to scale, with every tip carried on to a common column, or in the circular layout to the outer ring. Greyed in the unrooted layout, which has no column or ring to carry them to
     - all demos
   * - |cladogram|
     - cladogram: topology only, branch lengths ignored, every tip flush
     - all demos
   * - Time
     - lay the tree out by TIME (each branch at its stated length in time; from the node dates where the tree arrived showing divergence)
     - auspice, beast
   * - Div
     - lay the tree out by DIVERGENCE (substitutions per site: as the tree records it, or on a BEAST tree each branch's time x its clock rate)
     - auspice, beast
   * - Clock plot
     - clock plot: each tip's date against its divergence from the root, with a line through the tips (its slope is the rate); a panel linked to the tree
     - auspice, swh1, influenza

Node menu
---------

A click on a node, on its point or its label, opens a menu named after the
node. What it offers depends on the node: a tip cannot be collapsed, a child
of the root cannot be switched to or re-rooted on, the root has no menu, and
an entry the tree does not allow is greyed, with a tooltip that says why.

The labels and the greyed entries' reasons are read from the menu, opened on a tip, a
tip with an accession, an internal node and a child of the root of each demo tree
shown in the rectangular layout, and once more on the first demo launched with
``enableManualNodeSelection``, which adds two entries. The words of this table are
NOT the viewer's: its entries carry no tooltip, so they were written for this
reference and are to be checked like any draft.

     - all demos; with enableManualNodeSelection
   * - Switch to Subtree
     - show only the clade under this node, as a tree of its own (for a tip, its parent's clade); the whole-tree button of View & Tools, or Esc, returns to the whole tree
     - all demos; with enableManualNodeSelection
   * - Collapse/Uncollapse
     - fold the clade under this node into a wedge, or open it again; greyed for a tip and in the unrooted layout
     - all demos; with enableManualNodeSelection
   * - Uncollapse Subtree
     - open every collapsed clade under this node; greyed when nothing below it is collapsed
     - all demos; with enableManualNodeSelection
   * - Swap Descendants
     - exchange the order of this node's child clades
     - all demos; with enableManualNodeSelection
   * - Ladderize Subtree
     - order the clades under this node by size, largest first or smallest first in turn
     - all demos; with enableManualNodeSelection
   * - Reroot
     - re-root the tree on the branch above this node; when the new root would change the clade of an internal node that carries data, a warning says how many before anything changes
     - all demos but auspice, beast, sarscov2, caliciviridae\_500, adenoviridae, dinosaur, ammonite, late\_cretaceous, bcl2
   * - Reroot
     - Time trees can't be re-rooted: their branch lengths are times measured from this root.
     - auspice, beast, sarscov2, dinosaur, ammonite, late\_cretaceous; with enableManualNodeSelection
   * - Reroot
     - This tree is marked as not re-rootable (rerootable="false").
     - caliciviridae\_500, adenoviridae, bcl2
   * - Select/Deselect Node
     - add this node to the selection, or take it out; offered when the host page enables manual node selection
     - with enableManualNodeSelection
   * - Select/Deselect All Ext Nodes
     - add every tip under this node to the selection, taking out those already in it; offered when the host page enables manual node selection
     - with enableManualNodeSelection
   * - Download Ext. Node Data
     - download the tips under this node as a tab-separated table: name, taxonomy, sequence, branch length and one column per property
     - all demos; with enableManualNodeSelection
   * - List Sequences in Fasta
     - show the molecular sequences of the tips under this node in FASTA format, in a window to copy from; offered when the tree carries sequences
     - swh1, alignment\_nt, genome\_alignment, alignment, sequence\_logo
   * - Download Sequences in Fasta
     - download the molecular sequences of the tips under this node as a FASTA file; offered when the tree carries sequences
     - swh1, alignment\_nt, genome\_alignment, alignment, sequence\_logo
   * - Delete Subtree
     - remove this node and its whole clade from the tree on view; the visualizations and the search are recomputed on what is left; not offered in a subtree view
     - all demos but flu\_h5n1\_seg3; with enableManualNodeSelection
   * - Access DB [accession]
     - open the database record of this node's accession (NCBI protein or nucleotide, RefSeq, UniProt) in a new browser tab; offered when the node has one, among its properties or sequences or as a UniProt-style name such as CASP9\_HUMAN
     - flavivirus, herpes\_dnapol, caliciviridae\_500, adenoviridae, genome\_regions, influenza, confidences, branch\_events, flu\_h5n1\_seg3
   * - Delete External Node
     - remove this tip from the tree on view; the visualizations and the search are recomputed on what is left; not offered in a subtree view
     - all demos; with enableManualNodeSelection
