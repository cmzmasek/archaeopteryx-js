=============
Control panel
=============

Every control of the Archaeopteryx.js control panel, section by section in
the panel's order, with the icon it draws and what it does. The words are
the control's own tooltip, as the panel's cheat sheet lists them (the card
button in the panel header, "Control panel: what each control does"); no
row shows a live value. The panel draws a control only when the tree on view
gives it something to do, so this is the union over the 26 demo trees of
``demo.html``, and the last column says which of them show the control.
A control with two icons shows the one for what the next click will do.

Layout and display type
-----------------------

.. list-table::
   :header-rows: 1
   :widths: 24 56 20

   * - Control
     - What it does
     - Shown for
   * - |rectangular|
     - rectangular layout: the root at the left, the tips in even rows down the page
     - all demos
   * - |circular|
     - circular layout: the tree as a fan, every tip label carried out to a common ring
     - all demos
   * - |unrooted|
     - unrooted layout: equal-angle, drawing no root branch at all
     - all demos
   * - |phylogram|
     - phylogram: branch lengths drawn to scale, so the tips end ragged. Greyed in the circular layout, which always carries its labels to the outer ring, so there the aligned phylogram is the one drawn
     - all demos
   * - |aligned_phylogram|
     - aligned phylogram: branch lengths to scale, with every tip carried on to a common column, or in the circular layout to the outer ring. Greyed in the unrooted layout, which has no column or ring to carry them to
     - all demos
   * - |cladogram|
     - cladogram: topology only, branch lengths ignored, every tip flush
     - all demos
   * - Time
     - lay the tree out by TIME (each branch at its stated length in time; from the node dates where the tree arrived showing divergence)
     - auspice, beast
   * - Div
     - lay the tree out by DIVERGENCE (substitutions per site: as the tree records it, or on a BEAST tree each branch's time x its clock rate)
     - auspice, beast
   * - Clock plot
     - clock plot: each tip's date against its divergence from the root, with a line through the tips (its slope is the rate); a panel linked to the tree
     - auspice, swh1, influenza
